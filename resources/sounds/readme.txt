==============================================================================
collection of non-human sounds (i.e. no human voices) from different datasets
==============================================================================

IMPORTANT: 
it is preferred to select sounds recorded in a "close distance" and
with minimal reverberation so that it is possible to render the final result
with a more accurate behavior. Sounds should be MONO but they will be
converted by the verse scene rendering if needed.

NOTE: non-human voice sounds are supported only by scene syntax version 
MJR.MIN=0.2 (and above)
